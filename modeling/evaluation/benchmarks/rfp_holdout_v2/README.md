# RFP 검색 홀드아웃 벤치마크 v2

제목 재정렬 가중치를 정한 4개 seed 질의와 분리된 검증용 평가셋이다.

- 실제 전략계획서 30개를 대상으로 한다.
- 16개 기관과 AI, 의료, 기후, 농업, 우주, 재난 등 여러 분야를 포함한다.
- 질문은 문서 제목을 그대로 복사하지 않고 사용자의 자연어 요구 형태로 작성했다.
- 각 질문은 요구를 직접 충족하는 목표 문서 하나를 grade 2로 판정한다.
- 정답이 하나이므로 핵심 지표는 `success@5`, `MRR`, `nDCG@5`다.
- 기존 방식과 개선 방식은 같은 질의·인덱스·임베딩 모델로 실행하고 10,000회 paired bootstrap 95% 신뢰구간으로 비교한다.

이 벤치마크는 재현 가능한 회귀 검증용이다. 모든 가능한 관련 문서를 exhaustively 판정한 데이터는 아니므로 일반 검색 품질의 절대값으로 해석하지 않는다.

확정된 비교 결과는 [results.md](results.md)에 기록한다.
